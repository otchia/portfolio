e-RoomReserve

AI-Driven Smart Campus Space Optimization System

Official Title

e-RoomReserve: AI-Driven Smart Campus Space Optimization System with Real-Time Occupancy Detection and Autonomous Reservation Control using Bluetooth Low Energy (BLE) Technology

Overview

e-RoomReserve is an AI-integrated room reservation and occupancy monitoring system developed for St. Dominic College of Asia. It addresses inefficiencies in the school’s manual room scheduling process by combining a mobile and web application, BLE beacon-based presence detection using ESP32, a faculty approval workflow, automated staff notifications, AI-based room recommendations, and sentiment analysis of post-reservation feedback.

Problem

Campus rooms were managed through digital logbooks, verbal coordination, and visual inspection. That led to no-shows, double bookings, unverified occupancy, and extra work for faculty and staff. Users also had no way to find a suitable available room based on capacity, type, and amenities.

Key Capabilities

  • Paperless reservations, faculty approval, bulk class scheduling, and status tracking on mobile and web
  • ESP32 BLE beacon presence detection that verifies the user is near the room before activating a reservation
  • Real-time occupancy monitoring with automated vacancy handling after a configurable timeout
  • Staff alerts for BLE signal loss, overtime occupancy, and fallback physical inspection
  • AI room recommendations using content-based filtering when a preferred room is unavailable
  • Post-reservation feedback with VADER sentiment analysis to support facility decisions

Architecture

The system uses a four-layer architecture: a Presentation Layer (React Native/Expo mobile app and Next.js web portal), an Application Layer (Next.js API routes), a Data Layer (Firebase and Supabase), and a Device Layer (ESP32 BLE beacons). Role-based access covers students, faculty, utility staff, building administrators, and super administrators.
